# Repository structure

A validation audit of the airline domain of tau2-bench, pinned at tag `v2.0.0`, commit `989d3285ae669e49503324bdb9981bf14fccedeb`.
Each sampled task is checked against a fixed checklist (static reading, mechanical probes, agent runs); every verdict is one row of `audit_log.csv`, and the headline numbers are rebuilt from the CSV files by script.

## Layout

```
.
├── 14_claude_code_kickoff.md   task statement and rules of the audit
├── STRUCTURE.md                this map
├── checklist.md                the validation checklist (check ids 1a..6e, method per check)
├── schema.md                   columns and validation rules of audit_log.csv
├── sample.json                 the 20 sampled task ids and the pinned bench commit
├── audit_log.csv               one row per (task_id, check): the audit result
├── summary_numbers.md          headline numbers, Tables 1-5 (generated)
├── fig_defects.png             defect figure (generated)
├── analysis.ipynb              runs make_summary and shows the figure and the tables
├── cost.md                     API cost ledger (hard stop $30)
├── issues_draft.md             draft issue texts for the upstream repository (not filed)
├── .gitignore
├── scripts/                    pipeline code (all paths resolve to the repository root)
│   ├── static_scan.py          static no-op scan and text pre-screen over all 50 tasks (tau2 venv)
│   ├── probe_2h.py             WRITE-order permutation probe (tau2 venv)
│   ├── extract_tasks.py        one Markdown task card per task for review (tau2 venv)
│   ├── agent_rows.py           agent-run results -> audit rows, run summary, triage, transcripts
│   ├── probe_32.py             counterfactual user-simulator probe for task 32 (--dry makes no model call)
│   ├── summarize_run.py        short summary of a tau2 results.json (called by the run scripts)
│   ├── build_audit_log.py      merges all CSV inputs into audit_log.csv, then runs the validator
│   ├── validate_audit_log.py   checks audit_log.csv against schema.md (exit 0 = valid)
│   ├── rereview_agreement.py   blind re-review vs original labels (agreement, Cohen's kappa)
│   ├── make_summary.py         summary_numbers.md and fig_defects.png from the CSV files
│   └── runs/
│       ├── run_pilot.ps1       5-task pilot run with the Anthropic API (spends money)
│       └── run_sample20.ps1    Pass^3 and ground-truth-agent runs on the 20 sampled tasks (spends money)
├── results/                    intermediate CSV and Markdown outputs, review verdicts, skeptic reports
│   ├── static_scan.csv, probe_2h.csv, haiku_pass.csv, rereview.csv   generated by scripts
│   ├── review_*.csv / review_*.md        reviewer verdicts per check batch (hand-made inputs)
│   ├── skeptic_verdicts*.csv, skeptic_report*.md   adversarial review of defect rows
│   ├── rereview_blind.csv, rereview_summary.md     blind second pass on 3 tasks
│   ├── agent_runs_summary.md, agent_triage.md      agent-run summary and review list
│   ├── task_cards/             one card per task (generated by extract_tasks.py)
│   ├── trajectories/           readable transcripts of failed or flipped trials
│   ├── runs/                   copies of the run results.json files and run logs
│   └── probe_32/               protocol, samples and blind classifications of the task-32 probe
├── patches/                    recorded local patches to the tau2-bench checkout (not applied)
├── private/                    gitignored
└── tau2-bench/                 gitignored upstream clone
```

## Pipeline (inputs -> script -> outputs)

1. `tau2-bench/` (pinned clone), `sample.json` -> `scripts/static_scan.py` -> `results/static_scan.csv`
2. `tau2-bench/` -> `scripts/probe_2h.py` -> `results/probe_2h.csv` (verdicts are made by hand in `results/review_2h.csv`)
3. `tau2-bench/`, `results/static_scan.csv`, `sample.json` -> `scripts/extract_tasks.py` -> `results/task_cards/task_<id>.md`
4. Static review of the task cards (by hand) -> `results/review_batch_*.csv`, `results/review_ALL.csv`, `results/review_overrides.csv`
5. `scripts/runs/run_pilot.ps1`, `scripts/runs/run_sample20.ps1` (API calls) -> `tau2-bench/data/simulations/...`, copied to `results/runs/`
6. Simulation results, `results/static_scan.csv`, `sample.json`, run log -> `scripts/agent_rows.py` -> `results/haiku_pass.csv`, `results/agent_runs_summary.md`, `results/agent_triage.md`, `results/trajectories/`
7. Review of failed trajectories (by hand) -> `results/review_agent.csv`, `results/review_agent_overrides.csv`; skeptic review -> `results/skeptic_verdicts*.csv`
8. All CSV inputs above, `sample.json` -> `scripts/build_audit_log.py` -> `audit_log.csv` (then `scripts/validate_audit_log.py` runs)
9. `results/rereview_blind.csv`, review CSVs -> `scripts/rereview_agreement.py` -> `results/rereview.csv`, `results/rereview_summary.md`
10. `audit_log.csv`, `results/static_scan.csv`, `results/rereview.csv`, `results/runs/*.results.json` -> `scripts/make_summary.py` -> `summary_numbers.md`, `fig_defects.png`
11. `analysis.ipynb` -> imports `scripts/make_summary.py`, displays the figure and the tables
12. `tau2-bench/`, `results/runs/sample20_pass3_haiku.results.json` -> `scripts/probe_32.py` (API calls) -> `results/probe_32/`

## Rebuild everything (offline, no API calls)

From the repository root, PowerShell. Steps 1-4 need the tau2 virtual environment inside `tau2-bench/`; the others need Python 3.11 with pandas, matplotlib, statsmodels and jupyter.

```powershell
cd tau2-bench
$env:PYTHONUTF8 = 1
$uv = "$env:USERPROFILE\.local\bin\uv.exe"
& $uv run --no-sync python ..\scripts\static_scan.py
& $uv run --no-sync python ..\scripts\probe_2h.py
& $uv run --no-sync python ..\scripts\extract_tasks.py
& $uv run --no-sync python ..\scripts\agent_rows.py --log ..\results\runs\sample20.log
& $uv run --no-sync python ..\scripts\probe_32.py --dry     # optional; rewrites results\probe_32\setup.json (timestamp)
cd ..
python -I scripts\build_audit_log.py
python -I scripts\rereview_agreement.py
python -I scripts\make_summary.py --selftest
python -I scripts\make_summary.py
python -m jupyter nbconvert --to notebook --execute --inplace analysis.ipynb
```

`scripts/agent_rows.py` reads the simulation results from `tau2-bench/data/simulations/`; the same files are kept in `results/runs/`.
The `--log` path is resolved against the current directory.

## Where the headline numbers live

- `summary_numbers.md`: Table 1 (headline shares), Table 2 and 2b (confirmed defects by category and by check), Table 3 (low-severity defects), Table 4 (agent runs), Table 5 (blind re-review agreement).
- `fig_defects.png`: the defect figure built from the same data.
- `audit_log.csv`: the row-level source of every number.

## Not in git (`.gitignore`)

- `tau2-bench/`: the upstream benchmark clone; it is pinned by commit hash (in `sample.json` and `audit_log.csv`) instead of being vendored.
- `.env`, `.env.*`: API keys; never committed.
- `private/`: descriptions of scorer bypasses, kept out of publication.
- Python and OS noise (`.venv/`, `__pycache__/`, `.ipynb_checkpoints/`, `Thumbs.db`).

`README.md` and `report.md` are written separately by the owner.
