# Repository structure

A validation audit of tau2-bench (airline and retail), pinned at tag `v2.0.0`, commit `989d3285ae669e49503324bdb9981bf14fccedeb`.
Each task (all 50 airline and all 114 retail) is checked against a fixed checklist (static reading, mechanical probes, agent runs); every verdict is one row of `audit_log.csv`, and the headline numbers are rebuilt from the CSV files by script.

## Pipeline (inputs -> script -> outputs)

1. `tau2-bench/` (pinned clone), `sample.json` -> `scripts/static_scan.py` -> `results/static_scan.csv`
2. `tau2-bench/` -> `scripts/probe_2h.py` -> `results/probe_2h.csv` (verdicts are written by a model reviewer in `results/review_2h.csv`)
3. `tau2-bench/`, `results/static_scan.csv`, `sample.json` -> `scripts/extract_tasks.py` -> `results/task_cards/task_<id>.md`
4. Static review of the task cards (model reviewers) -> `results/review_batch_*.csv`, `results/review_ALL.csv`, `results/review_overrides.csv`
5. `scripts/runs/run_pilot.ps1`, `scripts/runs/run_sample20.ps1` (API calls) -> `tau2-bench/data/simulations/...`, copied to `results/runs/`
6. Simulation results, `results/static_scan.csv`, `sample.json`, run log -> `scripts/agent_rows.py` -> `results/haiku_pass.csv`, `results/agent_runs_summary.md`, `results/agent_triage.md`, `results/trajectories/`
7. Review of failed trajectories (model reviewers) -> `results/review_agent.csv`, `results/review_agent_overrides.csv`; skeptic review -> `results/skeptic_verdicts*.csv`
8. All CSV inputs above, `sample.json` -> `scripts/build_audit_log.py` -> `audit_log.csv` (then `scripts/validate_audit_log.py` runs)
9. `results/rereview_blind.csv`, review CSVs -> `scripts/rereview_agreement.py` -> `results/rereview.csv`, `results/rereview_summary.md`
10. `audit_log.csv`, `results/static_scan.csv`, `results/rereview.csv`, `results/runs/*.results.json` -> `scripts/make_summary.py` -> `summary_numbers.md`, `fig_defects.png`
11. `analysis.ipynb` -> imports `scripts/make_summary.py`, displays the figure and the tables
12. `tau2-bench/`, `results/runs/sample20_pass3_haiku.results.json` -> `scripts/probe_32.py` (API calls) -> `results/probe_32/`

## Setup

The scripts expect the upstream benchmark next to them in `tau2-bench/` (gitignored) and two Python environments.

```bash
git clone https://github.com/sierra-research/tau2-bench
cd tau2-bench
git checkout 989d3285ae669e49503324bdb9981bf14fccedeb
uv sync
```

`uv sync` creates `tau2-bench/.venv` (Python 3.12 was used here). Scripts that import tau2 run from `tau2-bench/` as `uv run --no-sync python ../scripts/<name>.py` in bash, or `& $uv run --no-sync python ..\scripts\<name>.py` in the PowerShell blocks below. The summaries, figures and the notebook need a separate Python 3.11 with `pandas`, `matplotlib`, `statsmodels` and `jupyter`, run with `-X utf8`. The retail agent runs used one recorded local patch to the checkout (`patches/nl_judge_haiku.patch`, a judge-model substitution); the offline rebuild and the demo do not need it.

## Rebuild everything (offline, no API calls)

From the repository root, PowerShell. Steps 1-4 need the tau2 virtual environment inside `tau2-bench/`; the others need Python 3.11 with pandas, matplotlib, statsmodels and jupyter.

```powershell
cd tau2-bench
$env:PYTHONUTF8 = 1
$uv = "$env:USERPROFILE\.local\bin\uv.exe"
& $uv run --no-sync python ..\scripts\static_scan.py
& $uv run --no-sync python ..\scripts\probe_2h.py
& $uv run --no-sync python ..\scripts\extract_tasks.py
& $uv run --no-sync python ..\scripts\agent_rows.py --log ..\results\runs\sample20.log
& $uv run --no-sync python ..\scripts\probe_32.py --dry     # optional; rewrites results\probe_32\setup.json (timestamp)
cd ..
python -I scripts\build_audit_log.py
python -I scripts\rereview_agreement.py
python -I scripts\make_summary.py --selftest
python -I scripts\make_summary.py
python -m jupyter nbconvert --to notebook --execute --inplace analysis.ipynb
```

`scripts/agent_rows.py` reads the simulation results from `tau2-bench/data/simulations/`; the same files are kept in `results/runs/`.
The `--log` path is resolved against the current directory.

## Block 2 rebuild (offline parts)

```powershell
python -I scripts\v2\make_tasks_v2.py --check          # tasks v2 equal the anchored edits
cd tau2-bench; $env:PYTHONUTF8 = 1
& $uv run --no-sync python ..\scripts\v2\scorer_v2.py --selftest
& $uv run --no-sync python ..\scripts\v2\noop_scan_v2.py
& $uv run --no-sync python ..\scripts\v2\rescore.py --no-judge          # gates + deterministic configurations
& $uv run --no-sync python ..\scripts\v2\rescore.py                     # adds the judge configurations; replays from judge_cache.json, no new calls once cached
& $uv run --no-sync python ..\scripts\v2\rescore.py --set fresh         # the v2 live runs under every protocol (judge_cache_live.json)
& $uv run --no-sync python ..\scripts\v2\rescore.py --set sonnet        # the Sonnet run under every protocol (judge_cache_sonnet.json)
& $uv run --no-sync python ..\scripts\v2\judge_handcheck.py --build     # hand-check items (no model call); --score needs only Python 3.11
& $uv run --no-sync python ..\scripts\v2\judge_reparse_check.py          # parser-gap check over the raw judge replies (no model call)
cd ..
python -I -X utf8 scripts\v2\make_summary_v2.py
```

Live parts (spend money; recorded in cost.md): `run_v2.py --part all` (pass3, gt, gt3), `noop_judge_probe.py`, `probe_32_v2.py [--tag v21]`, and the judge stages of `rescore.py`.

The judge, probe and live-run scripts refuse to run while `scripts/v2` or `block2` has uncommitted changes (set `V2_ALLOW_DIRTY=1` to override); every v2 output carries the overlay commit and a dirty flag.
